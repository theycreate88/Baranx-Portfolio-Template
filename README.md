📌 DESCRIPTION:
--------------
This is a modern and responsive personal portfolio website template designed for developers, designers, or freelancers. It includes smooth scrolling, animated sections, custom cursor, scroll-to-top button, and a split-screen opening animation.

📁 INCLUDED FILES:
------------------
- index.html
- style.css
- script.js
- /assets/images/
- license.txt
- README.txt (this file)

💡 FEATURES:
------------
- Fully responsive layout
- Smooth section scroll with scrollspy
- Custom animated cursor
- Scroll progress indicator
- Scroll-to-top button
- Split-screen intro animation
- Hamburger menu for mobile
 

📦 INSTRUCTIONS:
----------------
1. Unzip the folder.
2. Open `index.html` in your browser.
3. Customize text, images, and colors as needed in:
   - `index.html` (structure/content)
   - `style.css` (styling)
   - `script.js` (animations/interactions)
4. Replace image files in `/images/` with your own.
